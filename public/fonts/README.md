# The Seasons Font Assets

To use local font files for **The Seasons**, place the font files in this folder with any of the following names:
- `TheSeasons-Regular.woff2` or `TheSeasons-Regular.woff` or `TheSeasons.otf`
- `TheSeasons-Bold.woff2` or `TheSeasons-Bold.woff` or `TheSeasons-Bold.otf`

If these files are not present, the site automatically uses locally installed system fonts (`local('The Seasons')`) or falls back to Google Fonts (`Cormorant Garamond` and `Playfair Display`), preserving the editorial high-contrast serif aesthetic.
